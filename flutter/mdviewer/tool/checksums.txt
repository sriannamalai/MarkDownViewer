# SHA-256 checksums for release-published mobile binary zips, consumed by
# tool/fetch_binaries.sh. One entry per line: "<sha256>  <zipname>"
# (two spaces, matching `shasum -a 256` output — safe to paste directly).
#
# Entries are appended here at each release that ships mobile artifacts
# (libmdviewer-<version>-ios.xcframework.zip, libmdviewer-<version>-android.zip
# — <version> has no leading "v", matching .github/workflows/release-ffi.yml).
# fetch_binaries.sh refuses to download any zip without a matching entry,
# so this file must be updated before consumers can fetch a given release.
#
# No entries yet — v0.7.0 will be the first release to ship mobile
# artifacts; its checksums land here at release time.
